## Цель работы

Освоить полный цикл обучения нейронной сети «с нуля» на PyTorch (CPU):

- подготовить данные через `Dataset` и `DataLoader`;
- корректно разделить данные на train/val до вычисления статистик;
- реализовать прямой и обратный проход с ручным обновлением параметров
  **без** `torch.optim`;
- сравнить ручной шаг оптимизации со стандартным `torch.optim.SGD`;
- подобрать learning rate и построить кривые обучения;
- применить регуляризацию (dropout, weight decay, early stopping)
  и оценить её эффект на валидации;
- оформить воспроизводимый проект (seed, requirements.txt, README).

## Датасет

**Fashion-MNIST** — 60 000 изображений 28×28 в оттенках серого, 10 классов
одежды. Скачивается автоматически через `torchvision.datasets.FashionMNIST(
download=True)`.

- Источник: https://github.com/zalandoresearch/fashion-mnist
- Размер: 60 000 train-объектов (используются только они, разделение 80/20)
- Классы: T-shirt, Trouser, Pullover, Dress, Coat, Sandal, Shirt,
  Sneaker, Bag, Ankle boot
